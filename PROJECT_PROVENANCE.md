# Project provenance

## SaluteFace

SaluteFace is a Python research toolkit for protein sequence analysis,
dataset preparation, experimental watermarking, and reproducible evaluation.

SaluteFace was integrated into this repository in October 2026.

The current implementation is an experimental research toolkit.
It is not an implementation of DeepMind SynthID Bio.

## SchemaPilot

This repository also contains the earlier SchemaPilot project:
a structured-output validation and contract-testing framework
with Python and .NET implementations.

SchemaPilot source code, tests, and Git history are retained for
historical reference and technical compatibility.

Older SchemaPilot releases and commits must not be interpreted
as evidence that SaluteFace existed at those dates.

## Development history

Git history is preserved as recorded. Existing commit metadata is
not modified to imply a different development timeline.

## Verification

The repository maintains separate automated checks for SaluteFace
and the existing SchemaPilot implementation.
